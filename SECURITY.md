# Security Policy

## Contact

Report vulnerabilities to **security@fitsense.app** (or the operator address listed on the public site).

Do not file public GitHub issues for sensitive reports.

## Disclosure

- Acknowledge within 3 business days.
- Aim to provide a remediation plan within 14 days for high/critical issues.
- Coordinate disclosure; we prefer 90-day windows unless active exploitation requires faster action.

## Scope

In scope: FitSense API, web app, Android app, merchant integrations as documented.

Out of scope: third-party retailer systems, social engineering of staff, physical theft.

See also: `docs/security/PENTEST_SCOPE.md`, `docs/ops/INCIDENT_RESPONSE.md`.
